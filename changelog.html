2026-09-09 · v0.7 · Every push now ships with notes

Why: the team follows Discord, not git. From now on every push carries an entry here, and the same notes land in Discord, so anyone can see what changed and trace a change back to its commits.

Added

  • tools/ship.sh: one command that commits with the top entry as the message, pushes, republishes the public site, and posts the notes to Discord with a link to the exact commits.

  • CLAUDE.md: working rules for anyone, or any Claude session, touching this repo.
  • A public updates page, https://spencebiv.github.io/halation-mockup/changelog.html, built from this file on every ship. No account needed.

For the team

  • Expect one "Halation updates" post in Discord per push. The title is the update, the bullets are the notes, the first link is the public updates page.
  • The commit links open the private source repo, so they need a GitHub account that Spencer has invited. The GitHub-generated push cards in Discord link there too.

2026-09-09 · v0.7 · Design system v2 and the tools model

Why: the full repass: colours that mean one thing, a tool set that adapts per project, a clearly labelled prototype, and two shareable links.

Changed

  • One meaning per colour. Green is finished, amber is a clock running, red is stop, teal is moving on its own or the client's side, orange is you. Teal added quietly alongside the orange.
  • Tools come from the Workflow (Commercial, Events, Weddings on; Real Estate, Personal, Documentary, Freelance, Studio available). Personal projects show nothing money-shaped. Add or hide tools per project from the ••• menu.
  • Adaptive canvases: Hand, Lap, Bay. Press N for the notes drawer and the demo switches.
  • Media tab: year, then client, then project, then what was shared. Files is now the paperwork. Commercial and Events groups collapse. Example figures lowered 15 to 20 percent.
  • Landing page rewritten. Labelled Prototype everywhere. Two builds: landing and demo app.

Added

  • Research: colour system, what looks AI-made, the Apple event of Sep 9 2026, what makes software loved, modularity precedents, the Tools and Workflows specification, Design specification v2.
